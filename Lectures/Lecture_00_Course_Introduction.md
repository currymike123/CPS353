## What is This Course About?

This course is about building high-quality software.

We're moving beyond just writing code that *works*. We want to write code that is:
- **Safe from bugs**
- **Easy to understand**
- **Ready for change**

---

## The Iceberg Analogy

The code you write is just the tip of the iceberg.

![bg right:40% 90%](https://i.imgur.com/3Z9AnrG.png)

Below the surface, there's a massive foundation of design, testing, and process that makes software robust and maintainable. We will be exploring what's under the water.

---

## Course Philosophy

### 1. Safe From Bugs
- We will focus on techniques to prevent bugs from ever being created.
- **Topics:** Static checking, specifications, testing, and code reviews.

### 2. Easy to Understand
- Code is read more often than it is written. We will emphasize clarity and communication.
- **Topics:** Code style, documentation, and choosing good names.

### 3. Ready for Change
- Software is not static. It evolves. We will learn to design for change.
- **Topics:** Modularity, interfaces, and design patterns.

## What You Will Learn
