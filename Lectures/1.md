# Lecture 1: Development Environment Setup

---

## The Goal: A Productive Environment

Your development environment is your workshop. A well-organized workshop allows you to focus on the craft, not the tools.

**Our Philosophy:**
- **Automate the mundane:** Let the machine do the repetitive work.
- **Master your tools:** Deep knowledge of a few tools is better than shallow knowledge of many.
- **Consistency is key:** Your environment should be reproducible and feel the same everywhere.

This lecture is about building that workshop.

---

## The Foundation: The Command Line

Even with powerful IDEs, the command line (shell) is the fundamental interface for a developer.

- **Direct Control:** It's the most direct way to interact with your system.
- **Scriptability:** You can automate any task you perform on the command line.
- **Universality:** The shell is everywhere, from your laptop to a remote server in the cloud.

We will use the integrated terminal in VS Code to blend the power of the command line with the convenience of an IDE.

---

## Our Editor: Visual Studio Code

**Why VS Code?**
- **Lightweight & Fast:** Starts quickly, feels responsive.
- **Extensible:** A massive ecosystem of extensions for any language or workflow.
- **Excellent Git Integration:** Makes version control a seamless part of your process.
- **Great Community Support:** It's the industry standard for a reason.

## Setting Up VS Code for Java

1.  **Install:** Download from [code.visualstudio.com](https://code.visualstudio.com/).
2.  **Install the "Extension Pack for Java":** This is a meta-package from Microsoft that includes everything you need for a first-class Java experience.
    - Language Support (IntelliSense, code completion)
    - Debugger
    - Test Runner
    - Maven/Gradle support
3.  **Install the "Vim" extension:** To bring the power of Vim's modal editing into VS Code.

---

## Essential VS Code Settings (`settings.json`)

```json
{
    // Make the editor work for you
    "editor.formatOnSave": true,
    "files.autoSave": "onFocusChange",

    // Java-specific settings
    "java.format.settings.url": "https://raw.githubusercontent.com/google/styleguide/gh-pages/eclipse-java-google-style.xml",
    "java.format.settings.profile": "GoogleStyle",

    // For our Vim users
    "vim.easymotion": true,
    "vim.incsearch": true,
    "vim.useSystemClipboard": true
}
```
Open the command palette (`Ctrl+Shift+P`) and type "Open User Settings (JSON)" to configure.

## Supercharge Your Editing: VIM

VIM is not just an editor; it's a **language for manipulating text**.

**The "Why":**
- **Efficiency:** Composable, repeatable commands for complex edits. `d2w` (delete 2 words) is a simple example of this composition.
- **Ergonomics:** Keep your hands on the home row. No more reaching for the mouse or arrow keys.
- **The "Zen" of VIM:** Once it clicks, it feels like you are "speaking" to your editor.

We are learning the VIM *language* within the modern VS Code editor.

---

## VIM: The Next Level of Motions

**Basic Navigation:** `h j k l`
**Word-level Navigation:** `w` (next word), `b` (beginning of word), `e` (end of word)
**Line-level Navigation:** `0` (start of line), `$` (end of line)
**Searching:** `/` (search forward), `?` (search backward), `n` (next match)

**Operators + Motions = Action**
- `d`: delete
- `c`: change (delete and enter insert mode)
- `y`: yank (copy)

`d$` -> delete to end of line
`ci"` -> change inside the double quotes

## The Java Development Kit (JDK)

**JDK vs. JRE:**
- **JRE (Java Runtime Environment):** What you need to *run* a Java application.
- **JDK (Java Development Kit):_ What you need to *develop* a Java application. It includes the JRE plus the compiler (`javac`) and other tools.

We need the JDK.

---

## Installing the JDK with SDKMAN

Managing different Java versions for different projects is a common task. `sdkman` makes this easy.

1.  **Install SDKMAN:**
    ```bash
    curl -s "https://get.sdkman.io" | bash
    ```
2.  **Install Java:**
    ```bash
    # List available Java versions
    sdk list java

    # Install a specific version (e.g., OpenJDK 17)
    sdk install java 17.0.2-open
    ```
3.  **Verify:**
    `java -version` and `javac -version`

## Workshop: "Hello, World!" from Scratch

Let's put it all together.

1.  **From the command line:**
    ```bash
    mkdir hello-java
    cd hello-java
    touch HelloWorld.java
    ```
2.  **Add code to `HelloWorld.java`:**
    ```java
    public class HelloWorld {
        public static void main(String[] args) {
            System.out.println("Hello, Software Construction!");
        }
    }
    ```
3.  **Compile and Run:**
    ```bash
    javac HelloWorld.java
    java HelloWorld
    ```
4.  **Open in VS Code:** `code .`
    - Explore the Java extension features. See how it recognizes the code. Try the "Run" button above `main`.
