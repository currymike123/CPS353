The main branch has the starter code for the students, the solutions are on the 'solutions' branch.

Recommended: create a github classroom "assignment" from this template repo every semester, with just the main branch (not the 'solutions' branch), and give students the shortened URL \- this means they only get write access to their own (autogenerated) copy of the exercises. 

**Specific Exercises:**

- Apply the builder pattern (exercise1)
- Apply the wrapper pattern (exercise2)  
- Apply the listener pattern (exercise3)  
- Redesign code for streaming (exercise4)

**Details**

Checkpoint 4 doesn't really require any specific design patterns, and historically very few students have recognized that a visitor is a good fit for handling multiple input types. Lambdas etc are more useful for the actual project, but conceptually it's the 'actually write the code' step where design patterns mainly come up, so it seemed like a good fit for when to cover this material
